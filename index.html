Routing rule

18 or more correct out of 30 in Module 1 (60%) → Module 2, higher route.

17 or fewer correct → Module 2, lower route.

This threshold is the rule for this practice form only. The real exam uses a statistical model and publishes no raw cutoff.

What each module covers

Questions appear in domain order within each module. In each domain group the easiest question comes first and the hardest comes last. Two hard questions are never placed next to each other.
